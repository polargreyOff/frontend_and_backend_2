# Практические 15-16

В папке реализовано самостоятельное PWA-приложение для заметок на основе практик 13-14, расширенное под задания 15 и 16.

## Что реализовано

- HTTPS-ready сервер на `Express`
- архитектура `App Shell`
- динамическая загрузка страниц из `content/home.html` и `content/about.html`
- `Service Worker` с двумя кэшами:
  - shell-кэш для статических ресурсов
  - dynamic-кэш для `content/*` по стратегии `Network First`
- заметки в `localStorage`
- `Socket.IO` для realtime-рассылки события `taskAdded`
- push-уведомления через `Push API` и `web-push`

## Установка зависимостей

```powershell
cd practice_15-16
npm install
```

## HTTPS через mkcert

Если `mkcert` установлен, в папке проекта выполни:

```powershell
mkcert -install
mkcert localhost 127.0.0.1 ::1
```

В результате рядом с `server.js` должны появиться:

- `localhost.pem`
- `localhost-key.pem`

`VAPID`-ключи для push создаются автоматически при первом запуске сервера и сохраняются в `vapid-keys.json`.

## Запуск

```powershell
npm start
```

Основной адрес:

- `https://localhost:3001`, если сертификаты есть
- `http://localhost:3001`, если сертификаты не созданы

## Как проверить практику 15

1. Открой приложение.
2. Проверь `Application -> Service Workers`.
3. Проверь `Application -> Cache Storage`:
   `focus-notes-shell-v1` и `focus-notes-dynamic-v1`.
4. Включи `Slow 3G` и обнови страницу:
   shell должен появиться сразу, а контент догрузиться позже.
5. Отключи сеть и обнови страницу:
   приложение и заметки должны остаться доступны.

## Как проверить практику 16

1. Нажми `Включить уведомления`.
2. Открой вторую вкладку с тем же адресом.
3. В первой вкладке добавь заметку.
4. Во второй вкладке должна появиться toast-подсказка и новая заметка.
5. Если вторая вкладка неактивна, должно прийти системное push-уведомление.
6. После `Отключить уведомления` push должен перестать приходить, а WebSocket останется работать.
