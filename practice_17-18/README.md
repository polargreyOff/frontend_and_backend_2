# Практика 17

В папке реализовано приложение для заметок и напоминаний на основе прошлых PWA-практик.

## Что реализовано

- обычные заметки и заметки с напоминанием
- хранение заметок в `localStorage` с полями `id` и `reminder`
- планирование push-напоминаний на сервере через `setTimeout`
- `Map` с активными таймерами на сервере
- браузерное уведомление о напоминании
- push-уведомление с action-кнопкой `Отложить на 30 секунд`
- обработка `notificationclick` в `Service Worker`
- App Shell, offline-режим и push-подписки из прошлых практик

## Установка зависимостей

```powershell
cd practice_17
npm install
```

## Запуск

```powershell
npm start
```

Основной адрес:

- `https://localhost:3001`, если рядом есть `localhost.pem` и `localhost-key.pem`
- `http://localhost:3001`, если сертификатов нет

## Как проверить

1. Открой приложение.
2. Нажми `Включить уведомления`.
3. Добавь обычную заметку и проверь, что она сохранилась.
4. Добавь заметку с напоминанием на 1-2 минуты вперёд.
5. Дождись push-уведомления.
6. Нажми `Отложить на 30 секунд`.
7. Убедись, что через 30 секунд уведомление приходит повторно.
